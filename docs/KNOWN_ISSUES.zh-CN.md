# 已知问题与适用边界

[English](KNOWN_ISSUES.en.md)

这是预览版本，以下限制尚未修复：

1. 同毫秒启动且乱序完成的检查，在历史恢复或压缩时可能选错最新比较基线。
2. 不同财务输入的缓存记录可能持续保留，压缩不保证把活跃项目限制在预期大小内。

其他边界：

- 同一工作区内已加载的会话共享去重、基线与财务缓存；但多个 DSH 进程共享同一记忆目录时不保证写入协调。
- 持久化记录中结构不可信的行会被整条跳过，因此损坏的历史可能少几条记录，而不是阻止启动或冒充通过。
- 财务、审计与监理只看到报送材料，无法自行读取缺失上下文；引用匹配不证明推理正确。
- 门禁不覆盖所有通过通用命令执行器产生的改动，也不保证每个函数都已报审。
- 财务缩小范围后需要报送方重新整理材料，不自动裁剪文件或修改目标。
- 模块意见进入规划的后续处理仍由主 Agent 组织；科研文档的节间/章间流程不包含在此版本。
- 不保证特定缺陷检出率、零误报、零漏报或节省 token；最终判断由使用者负责。

反馈问题时请描述宿主版本、模型标识、触发步骤与预期行为，避免提交凭据、私人代码或未经允许的日志。
